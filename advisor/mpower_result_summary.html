2.2   Four TWF clock errors (commands ignored)
Error: Clock ... u_pll_wrapper/u_gmux/clk_and_EnCGChk/o already exist, command ignored
Error: Clock ... u_rts_clk_rst_ctrl/dnt_ckbuf_rts_clk/o already exist, command ignored

Meaning: The TWF redefines clocks already declared; mPower ignores the duplicate, keeping the first definition.

Risk: If the ignored definitions carried different periods/windows, toggle timing on those clock branches may be wrong. These are on u_rts_clk_rst_ctrl — the same block as the worst dynamic IR (2.1).

Action: Check the TWF generator; deduplicate clock declarations or confirm the retained definition is correct.

2.3   TWF parsing quality — 130,880 unrecognized-keyword warnings (PWR-272)
  • PWR-272: Unrecognized keyword "#" — TWF contains comment/header lines mPower can't parse (#, #1)…), 130,880 occurrences.
  • PWR-297: Timescale is not defined, using seconds as default — no timescale in TWF.
  • Warning: No instances found in twf. Please check corresponding section.

Action: The TWF format looks partially non-conformant. Confirm -type format2 matches the file, and that the missing timescale/instance section is intentional — this can silently degrade timing-window accuracy.
